# Dota Timer

一个 Windows 桌面悬浮计时器，适合 Dota 游戏时间提醒。

## 功能

- 应用名称：Dota Timer
- 细长小条窗口，默认约 520x82 像素，接近 10-15cm 长、2cm 高
- 标题栏最小化按钮可隐藏到右下角托盘，计时和提醒会继续后台运行
- 标题栏“钉”按钮可固定/取消固定在屏幕最上层
- 可设置初始分钟和秒数
- 支持开始、暂停、继续、重置
- 每分钟第 40 秒语音提醒“屯野”
- 每个奇数分钟第 30 秒语音提醒“神符”
- 每 6 分钟第 30 秒语音提醒“经验符”
- 程序会常驻右下角系统托盘
- 托盘右键菜单可单独开关：鼠标穿透、40秒屯野语音、神符语音、经验符语音

## 使用方法

1. 双击运行 `DotaTimer.exe`。
2. 如需从指定时间开始，先设置“初始时间”的分钟和秒数。
3. 点击“开始”开始计时。
4. 点击标题栏的最小化按钮，可以隐藏到右下角托盘，计时和提醒会继续运行。
5. 点击标题栏的“钉”按钮，可以切换是否固定在屏幕最上层。
6. 在右下角系统托盘中右键 `Dota Timer` 图标，可以显示窗口、管理鼠标穿透和三个提醒开关。

## 使用建议

- 游戏请使用无边框窗口化或窗口化全屏，普通桌面置顶窗口才更容易显示在游戏上方。
- 鼠标穿透开启后，可在右下角系统托盘图标右键菜单中关闭。
